Selected projects

Featured project · Academic project, 2026–2027

Sentinel: AI Attendance Agent

A browser-based attendance system in which an AI agent handles roll-call. It captures a camera frame, sends it to a Roboflow detection model and marks the matched student present.

  • Uses a clear workflow: detect, identify, verify, decide and commit.
  • Skips detections below an adjustable confidence threshold and prevents a student from being marked more than once per day.
  • Can run when a button is pressed or automatically at a set interval, with live agent reasoning and an activity log.
  • Includes a dashboard, searchable records and CSV export. Demo mode allows use without a trained model.
  • Built with HTML, CSS and JavaScript in one file. All 20 test cases passed.
Web app · Runs on Claude

Fieldbook: Pet Care Agent

Brings pet profiles, medicines, vaccinations, reminders and vet visits together in one place. Its AI assistant responds to everyday care questions and offers general symptom guidance, while clearly stating that it is not a veterinary diagnosis.

Explainable AI for Diabetic Retinopathy Screening in Rural India

A low-cost screening assistant designed for health workers. It checks retinal image quality, estimates diabetic retinopathy severity and highlights the image regions that influenced its result. Cases with uncertainty are referred to a specialist for remote review. The system is intended to support doctors, not replace them.

  • Offline-first design, with reports in local languages such as Marathi and Hindi.
  • Planned approach: a CNN transfer-learning model, Grad-CAM heatmaps and an uncertainty category.
